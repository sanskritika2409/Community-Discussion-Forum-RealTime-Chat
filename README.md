# 🚀 Fullstack Web Application

A fullstack web application built using the MERN stack with authentication, real-time features, and a modern UI.

---

## ✨ Features

- User Authentication (Login/Register)
- Protected Routes
- Responsive UI
- Real-time updates (Socket.io if used)
- REST API integration
- Dashboard after login
- MongoDB database integration

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- React Router
- Axios
- CSS / Tailwind / Bootstrap (whichever you used)

**Backend:**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Socket.io (if used)

---

## 📁 Project Structure


client/ → Frontend (React)
server/ → Backend (Node/Express)
